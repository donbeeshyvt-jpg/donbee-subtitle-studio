# Donbee Subtitle Studio｜冬比字幕工作室

[English](README.en.md) · [安裝與模型設定](guides/SETUP.md) · [API／CLI 手冊](guides/API_CLI.md)

剪一段精華，光是下載影片、找片段、上字幕，就得開好幾個工具嗎？

冬比字幕工作室把這幾件事放在同一個本機網頁裡。貼上 YouTube 連結，指定要的時間區間與儲存資料夾，接著轉錄、校字、剪輯、輸出。你也可以直接匯入手上的影片或音訊，從字幕開始做。

目前是第一個公開程式版本 **v2.0.0-preview.1**。這裡的 v2 指網頁工作臺，preview 表示仍需要實際使用回饋，並非所有情境都已驗收。

## 可以拿來做什麼？

- 只取需要的 YouTube 片段：輸入起訖時間，可一次指定多段，選擇影片或純音訊，保存到指定資料夾。
- 在自己電腦算字幕：使用 Breeze-ASR-25、Whisper large-v3 或 Qwen3-ASR-1.7B，輸出可帶進剪輯軟體的 SRT 字幕檔。
- 接上自己的 AI 校字：本機可接 LM Studio／llama.cpp，線上可接 OpenRouter／DeepSeek。加上角色名、作品名和參考資料，讓模型依上下文提出修正，保留修改紀錄。
- 邊聽邊修：字幕點一下就能跳回對應位置，搭配時間軸調整片段順序、分段輸出或合併輸出，也能請 AI 整理摘要與重點。

想用線上轉錄，也有 ElevenLabs 和 OpenRouter 接口；需要自己的金鑰、可用模型與傳送音訊的同意。選遠端轉錄時，目前流程仍包含本機草稿階段，不能當作完全不需本機模型的模式。

## 一段影片，這樣走完

1. 開啟工作室，建立新專案。在「下載與剪輯」貼上 YouTube 連結，或匯入本機檔案。
2. 填入時間，例如 `05:00–10:00`，選擇下載位置，再開始下載。成品會放在所選位置下的 `subtitle_studio` 資料夾。
3. 切到「字幕與校字」，選擇已安裝的轉錄模型。人名或遊戲名容易聽錯的話，先填術語提示。
4. 選擇自己的文字模型校字。網頁的「直接套用」會寫入通過檢查的修正，完成後看新舊比對，必要時整批還原。想先看建議不改稿，可用 CLI；高信心標記也不代表一定正確，重要片段還是要聽一次。
5. 預覽字幕，選擇一句或兩句一條、是否保留標點，輸出 SRT。需要影片的話，再到剪輯頁輸出片段。

> 兩個下載區間如果重疊，會合併取得。例如 5–10 分與 9–15 分，會取得 5–15 分，避免重複下載；要兩份成品，請在時間軸分成兩段再輸出。精準裁切需要重新編碼，速度與畫質取捨和直接複製串流不同。

原始素材不會被覆寫。影音輸出遇到同名會另取檔名；字幕與文字紀錄在同一輸出位置會更新同名最新版，想保留不同成品請選不同資料夾或另外備份。

## 開始前先準備

以 Windows、Python 3.12 為主要使用環境；需有 FFmpeg（含 ffprobe）及 Node.js。首次啟動會建立專案的 Python 環境並安裝所需套件，可能需要下載不少資料；模型權重需另外準備。GPU 是否可用、模型能否放進顯示記憶體，也會影響能跑的組合。

第一次下載 YouTube 前，還要準備 yt-dlp 下載環境。完整指令與模型安裝方式放在[安裝手冊](guides/SETUP.md)。LM Studio 是選用工具，使用前請自行開啟並載入模型。

這個專案不附影片、模型權重、金鑰或個人的開發紀錄。下載與使用影音前，請確認自己有權使用素材。

## AI 工具要去哪裡準備？

- [OpenRouter](https://openrouter.ai/)：想接線上文字模型，先註冊帳號、取得 API 金鑰，再回工作室設定。是否需要儲值依你選的模型與服務方案而定。
- [LM Studio](https://lmstudio.ai/)：想用自己的電腦校字，到官網下載程式、載入模型並開啟本機伺服器。這是本機工具，不是必須申請的線上轉錄服務。
- [ElevenLabs](https://elevenlabs.io/)：想用線上語音轉文字，註冊後準備具備 Speech to Text 權限的 API 金鑰，再回工作室測試連線。

這些都是選用服務。金鑰由你自己保管，遠端處理會送出對應音訊或文字，也可能產生費用。

## 用了哪些程式？

網頁用 React／TypeScript，後端用 Python／FastAPI；yt-dlp 負責解析下載來源，FFmpeg 處理影音，語音辨識串接 WhisperX／faster-whisper 等工具。部分時間軸與片段操作改寫自 LosslessCut，並不是完整的 LosslessCut。授權與來源見[第三方通知](THIRD_PARTY_NOTICES.md)。

## 最後，怎麼一鍵調用？

完成首次準備後，在專案資料夾雙擊 **`run_v2.bat`**。它會啟動本機服務並開啟瀏覽器：

[開啟冬比字幕工作室](http://127.0.0.1:8765/v2/)

如果要交給 AI 幫你操作，讓它先讀 [AGENTS.md](AGENTS.md) 與[操作 SKILL](.agents/skills/subtitle-studio/SKILL.md)，再告訴它影片連結、時間範圍、輸出位置，以及能否使用付費／遠端模型。CLI 也能把已建立的工作計畫一次跑完，範例在 [API／CLI 手冊](guides/API_CLI.md)。
